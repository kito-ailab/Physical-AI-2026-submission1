## Physical AI 応用編1｜知能ロボティクス講座 最終課題
#### OpenDuck Mini：強化学習PPOによる二足歩行とお盆運搬への挑戦

## 概要
小型二足歩行ロボット OpenDuck Mini V2 を対象に、強化学習（PPO）によって安定した二足歩行を獲得し、さらに頭部にお盆とコップを載せた状態での運搬動作の学習に取り組みました。

MuJoCo / MJXによる物理シミュレーション環境を使用し、JAX・Braxを用いたPPO学習を実施しています。

### 学習内容
学習は次の2段階で構成しています。
① 二足歩行PPO
お盆を載せない状態で、安定した前進歩行を学習しました。
② お盆運搬PPO
続いて、頭部にお盆とコップを載せた状態で、歩行と物体保持の両立を目指しました。
※動画はすべて等倍です。

### 使用技術
ロボット：OpenDuck Mini V2
物理シミュレーション：MuJoCo / MJX
強化学習：PPO（Proximal Policy Optimization）
学習フレームワーク：JAX / Brax
実行環境：Google Colab
